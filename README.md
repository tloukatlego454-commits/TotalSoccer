## 3. Search Engine Optimization (SEO) & Security

### On-Page SEO
- **Keywords:** Integrated terms like "soccer boots South Africa" and "authentic soccer jerseys" into meta tags and content.
- **Title & Meta Descriptions:** Added unique, compelling descriptions to the `<head>` of every HTML page.
- **Header Tags:** Used one `<h1>` per page, with logical `<h2>` and `<h3>` hierarchy for content structure.
- **Image Optimisation:** Added descriptive `alt` text to all images for accessibility and image search ranking.
- **Mobile-Friendly:** Implemented responsive CSS using Flexbox, Grid, and media queries to ensure mobile compatibility.

### Off-Page SEO
- **Backlinks:** Plan to reach out to local soccer blogs and sports news websites for guest posting and backlinks.
- **Social Media:** Promoted the website on Facebook, Instagram, and Twitter to drive traffic and build brand signals.
- **Local SEO:** Created a Google Business Profile for the Vaal headquarters and listed all 5 store locations on Google Maps.

### Technical SEO & Security
- **robots.txt:** Created and uploaded to the root directory to instruct search engine crawlers.
- **sitemap.xml:** Created and linked in robots.txt to help search engines index all pages.
- **Page Speed:** Optimised images, minified CSS/JS, and reduced server requests to improve load times.
- **Security:** 
  - *Plan for Live Deployment:* Will implement an SSL Certificate (HTTPS) to encrypt data.
  - *Plan for Live Deployment:* Will use a Web Application Firewall (WAF) and secure contact forms with reCAPTCHA to prevent spam/attacks.
